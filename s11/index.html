Pre-launch website QA report

Sample report: one page reviewed in desktop and mobile views

This is a format sample. The reviewed page is a demo accounting-firm page built only for this sample, so no client's work is shown. A real report covers every page in scope (20–25 pages) in the same format.

Summary

8issues found
3high (fix before launch)
2medium
3low

Affected view: Desktop only 1, Mobile only 3, both 4.

How each page is checked

AreaWhat is checked, in both views
ContentSpelling, grammar, punctuation, Australian English (organise, optimise, licence/license, centre)
ConsistencyTerms, headings, capitals and button labels compared across all pages
VisualSpacing, alignment, type, images, buttons
ResponsiveDesktop 1280 px and mobile 390 px: wrapping, overflow, sideways scroll, tap targets
FunctionEvery menu and footer link, buttons, mobile menu, contact form (required fields, error and thank-you messages)

Issues

#1HighBothContent quality

Page: Home  ·  URL: /

Issue: Spelling error in the main heading: "acounting".

Recommended correction: Change to "accounting". Same heading on mobile.

Desktop 1280 px

#2MediumBothAustralian English

Page: Home  ·  URL: /

Issue: "organize" uses US spelling, while the Business advisory card uses "optimise".

Recommended correction: Use "organise" so the page follows Australian English throughout.

Desktop 1280 px

#3LowBothConsistency

Page: Home  ·  URL: /

Issue: The Bookkeeping card says "Read More ›"; the other two cards say "Learn more" (different wording, capitals and arrow).

Recommended correction: Use "Learn more" on all three cards.

Desktop 1280 px

#4LowDesktopConsistency

Page: Home  ·  URL: /

Issue: Menu mixes title case ("Tax Planning", "Business Advisory") with sentence case ("About us").

Recommended correction: Pick one style, e.g. "About Us", and match it in page headings.

Desktop 1280 px

#5HighMobileFunctionality

Page: Home  ·  URL: /

Issue: The menu icon does nothing when tapped. On mobile no page other than this one can be reached from the header.

Recommended correction: Connect the icon to the mobile menu (check open, close, and that every link works).

Mobile 390 px (iPhone 12–15 size)

#6HighMobileResponsiveness

Page: Home  ·  URL: /

Issue: The Fixed fees table has a fixed width of 720 px. On a 390 px phone the "Includes" column is cut off and the whole page scrolls sideways (red line = screen edge).

Recommended correction: Let the table shrink to the screen (width: 100%) or stack rows as cards below 700 px.

Mobile 390 px (iPhone 12–15 size)

#7LowMobileVisual quality

Page: Home  ·  URL: /

Issue: The consultation button does not wrap: it runs to 6 px from the right edge, while all other content keeps an 18 px margin.

Recommended correction: Allow the label to wrap, or shorten it to "Book a free consultation".

Mobile 390 px (iPhone 12–15 size)

#8MediumBothContent quality

Page: Home  ·  URL: /

Issue: Footer shows "© 2024" and has no phone, email or contact link.

Recommended correction: Update the year for launch and add the contact details or a Contact link.

Desktop 1280 px
